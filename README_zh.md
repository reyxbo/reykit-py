# reykit

**reykit** 是一个 Python 通用工具方法集成包。

提供数据处理、网络请求、文件操作、图片处理、日志、随机数、正则表达式、定时任务、系统操作、表格处理、多任务、文本处理、时间处理、装饰器等常用工具方法。

同时提供 DLL 文件、邮件、标准输入输出等功能模块，并通过模块化设计集成常用的 Python 开发工具能力，减少重复编写基础工具代码。

适用于 Python 应用开发中的通用工具方法调用和基础功能集成。

## 特性

* 提供丰富的 Python 通用工具方法
* 模块化设计，可按需使用不同功能
* 提供统一的方法导出接口
* 提供 Python 基础数据类型处理方法
* 提供 JWT、bcrypt 等编码解码方法
* 提供电子邮件发送及内容处理方法
* 提供图片压缩、二维码及验证码处理方法
* 提供程序日志及运行数据存储方法
* 提供 HTTP、URL、Cookie、Socket 等网络处理方法
* 提供文件、文件夹及临时文件处理方法
* 提供随机数及随机数据处理方法
* 提供正则表达式处理方法
* 提供数据库定时任务集成方法
* 提供标准输入输出及终端打印处理方法
* 提供操作系统、进程、内存及环境相关方法
* 提供表格数据转换及处理方法
* 提供线程、协程等多任务处理方法
* 提供文本及字符串处理方法
* 提供时间处理及执行时间统计方法
* 提供丰富的装饰器方法
* 提供 Windows DLL 文件注入方法

---

## 安装

要求 **Python 3.12 或更高版本**。

```bash
pip install reykit
```

# 模块

reykit 按功能划分为多个模块，各模块负责不同的通用工具及基础功能。

## `rall` — All import methods

**统一导出模块。**

提供 reykit 所有模块方法和对象的便捷导出，可以通过该模块集中导入框架提供的功能，减少从多个模块分别导入的代码。
